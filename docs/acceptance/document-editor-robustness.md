# 即时编辑器健壮性 · 验收清单

验收对象：Space 文档（`alter-doc/1` AST）的即时编辑器——在面板中直接编辑 AST 文档的编辑面。
正文只有这一种格式，所有 note 都走该结构化编辑器。

结论口径：健壮性以「每条失败路径都有兜底与回归」为验收原则，不以功能齐全为准。A–C 组为 P0，任一
未通过即整体不通过；D–F 组为 P1；G 组是支撑上述结论的回归与自动化要求。

状态标记：`[x]` 自动化覆盖；`[~]` 已实现、依赖运行时未联调；`[ ]` 未做。当前 P0 保存生命周期、
P2 评论/历史与 P5 AI 块级 patch 已部分落地（见[编辑器体验重建清单](editor-experience-p0-p6.md)），
对应条目已按证据标记；其余仍按清单推进。实施后只改标记，不追加历史。

验收环境：DSH 桌面 profile 与真实桌面应用；测试文档用 Agent 文档工具生成，不手工改库。
自动化项在实施阶段随代码补充；未自动化前按「人工」执行，并在验收时记录可复现步骤。

## A. 数据安全（P0）

- [x] **A1 未保存内容可恢复**：编辑后不手动保存，切换文档或关闭再打开同一文档 → 编辑内容可恢复
  （自动保存或草稿任一机制），并有可见的恢复状态；无静默丢失。
- [~] **A2 崩溃/强制退出可恢复**：编辑中断，强制退出应用后重启打开文档 → 最近未保存输入可恢复，
  或明确告知不可恢复；不得静默丢弃。
- [x] **A3 保存期间继续输入不丢**：在保存请求进行中继续输入，保存完成后 → 新输入仍在且标记未保存，
  不被保存回执覆盖。
- [x] **A4 保存不破坏编辑连续性**：保存后立即撤销 → 可回到保存前；光标、选区与滚动位置保留；
  撤销历史不因保存清空。
- [x] **A5 保存失败可安全重试**：保存超时、断网或宿主重启后重试 → 不产生重复 revision 或重复内容；
  已提交但回执丢失时能和解出「已保存」，不误报冲突；本地输入全程保留。

## B. 并发与恢复（P0）

- [x] **B1 人与 Agent 并发不丢输入**：用户编辑未保存时 Agent 写入同一文档，用户再保存 → 本地输入
  有去处（保留草稿、对比、合并或另存），不出现「只能重新加载并丢弃」的唯一下场。
- [x] **B2 冲突有可操作路径**：任一保存冲突 → 界面提供不少于两种下一步（如保留草稿后重载、对比后
  合并、另存副本），选择任一路径都不丢本地方编辑。
- [ ] **B3 双入口不静默覆盖**：同一文档在两个编辑入口同时打开并各自保存 → 后保存方收到冲突与保留
  路径，先保存方内容不被静默覆盖。
- [ ] **B4 版本恢复不覆盖脏状态**：未保存编辑存在时恢复历史版本或接收外部更新 → 先提示并保留当前
  草稿，不静默替换正文。

## C. 变更与保存可行性（P0）

- [x] **C1 大变更可保存**：对不少于 64 个顶层块的文档执行全选替换、清空或大重排 → 保存成功（允许
  分段完成并显示进度），不出现「变更过大无法保存」的死路。
- [ ] **C2 模型上限附近保存完整**：接近单文档上限（5000 块 / 512 KiB）的文档保存后重新打开 → 块数、
  结构与内容一致，无截断或丢块。
- [~] **C3 粘贴/拖放/媒体不静默丢内容**：从网页、飞书或 Notion 粘贴富文本、表格、代码与图片，或
  拖入图片文件 → 支持的结构保留；不支持的结构有明确降级提示；图片进入资产，不以 data URL 进正文
  且不被丢弃。
- [~] **C4 粘贴内容安全**：粘贴含脚本、危险链接或未知富对象的 HTML → 无可执行内容进入文档，危险
  链接被剥离或有可见降级，不产生 XSS。

## D. 输入健壮（P1）

- [~] **D1 中文/日文 IME**：在标题、段落、列表项、任务项与表格单元格中连续输入、取消候选、组词
  中途保存 → 光标不跳、不丢字、不重复；未完成的组合输入不会被保存为半成品。
- [ ] **D2 空块语义正确**：空行、空标题、空列表项、空表格单元格经过编辑→保存→重开往返 → 结构与
  内容不变；空行与空列表项不消失，空容器不塌陷。
- [ ] **D3 空列表项删除行为正确**：列表中间的空列表项退格或向前删除 → 列表保持连续、序号正确，
  光标落在可继续输入的位置。
- [ ] **D4 撤销语义统一**：保存后撤销、跨保存撤销、服务端撤销与版本恢复组合使用 → 行为符合单一
  已定义约定，不出现「保存后无法撤销」或「撤销与版本恢复互相打脸」。
- [ ] **D5 键盘与无障碍**：工具栏可键盘到达与操作，编辑器与状态有可读的语义标签，屏幕阅读器不
  产生错误播报或焦点陷阱。

## E. 正确性与异常（P1）

- [ ] **E1 异常不白屏**：加载未知节点、缺失引用、超限或损坏文档 → 只读降级或明确错误页，面板不
  崩溃，可返回其他文档。
- [ ] **E2 异常可诊断**：编辑或保存异常有用户可见错误与恢复入口（重试、导出草稿、另存），开发侧有
  日志或遥测入口，不依赖重现用户现场。
- [x] **E3 标题与正文一致**：标题与正文并发保存 → 两者都落库、不互相交错覆盖；版本与更新时间语义
  与二者变更一致。
- [~] **E4 锚点在编辑后有效**：已启用的正文锚定（评论或引用）在编辑、块重建或版本恢复后 → 可定位
  或被明确标记失效，不静默指向错误位置。

## F. 规模与性能（P1）

- [ ] **F1 上限文档可交互**：5000 块 / 512 KiB 文档加载到可编辑 → 首屏指标达成（暂定 ≤3s，基线
  测量后锁定）。
- [ ] **F2 输入延迟**：上限文档连续输入 → 按键响应 p95 ≤50ms（暂定，基线测量后锁定）。
- [ ] **F3 保存延迟**：上限文档保存 → 本地往返 ≤1s，过程中无连续超过 100ms 的长任务卡顿（暂定）。
- [ ] **F4 内存**：同一文档反复打开、关闭 20 次 → 内存无显著增长或泄漏。

## G. 回归与自动化（P1）

- [x] **G1 映射往返**：AST→编辑器→AST 对全部节点类型与属性幂等（自动化）。
- [ ] **G2 随机操作序列**：随机编辑序列产生的保存请求总能被 Host 接受，结果文档通过 schema 校验
  （自动化）。
- [ ] **G3 浏览器级用例**：IME、粘贴、空块、大文档与断网重试在真实浏览器稳定复现（自动化优先，
  未自动化前保留人工记录）。
- [ ] **G4 故障注入**：保存超时、宿主重启、数据库忙、回执丢失等故障下输入不丢且可恢复（自动化）。
- [~] **G5 文档同步**：实施范围、验收状态与代码在同一变更里更新；清单通过后状态改为 `active`。
